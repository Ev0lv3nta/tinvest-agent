# tinvest-agent

Стенд для наблюдения за автономным торговым агентом в песочнице T-Invest API.

Агент работает сам: просыпается по собственному расписанию, изучает рынок,
принимает решения и торгует. Задача стенда — не заработать, а увидеть, как он
это делает, и получить журнал, по которому решения можно разобрать постфактум.

Деньги в песочнице виртуальные. Боевой контур не подключён и подключаться не будет.

## Устройство

```
supervisor  ──stdio──>  codex app-server  ──MCP──>  gateway
     │                                                 │
     ├── таймеры, дедмен, healthcheck                  ├── T-Invest sandbox (REST)
     ├── Telegram в обе стороны                        ├── веб-поиск
     └── журнал в SQLite                               └── журнал в SQLite
```

`supervisor` держит одну длинную сессию агента и доставляет в неё сообщения:
сработавший будильник, реплику из Telegram, регулярную проверку. Сам агент
внутри сессии не перезапускается, поэтому контекст между пробуждениями не теряется.

`gateway` — MCP-сервер с торговыми инструментами. Живёт отдельным процессом вне
рабочей директории агента: агент правит свои заметки и стратегию, но не журнал
сделок и не ограничители.

## Ограничения

Заданы в коде, а не в инструкциях:

- стартовый капитал 100 000 ₽, пополнений по ходу нет;
- плечо запрещено — заявка на сумму больше свободных денег отклоняется;
- шорт запрещён — продать больше, чем есть в портфеле, нельзя;
- не более 30 заявок в час.

Песочница не считает маржинальные показатели и допускает отрицательный баланс,
поэтому проверки делаются на нашей стороне до отправки заявки.

## Требования

Python 3.11+, ничего сверх стандартной библиотеки. Codex CLI с
`codex-code-mode-host` — без него MCP-инструменты не доедут до модели.

Сертификат `deploy/RussianTrustedRootCA.pem` нужен для TLS до API Т-Банка:
цепочка подписана Минцифры, в системных хранилищах её нет. Передаётся клиенту
явно, системное хранилище не трогается.
