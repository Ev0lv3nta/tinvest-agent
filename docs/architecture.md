# Архитектура

## Почему одна длинная сессия

`codex exec` — одиночный запуск: промпт внутрь, результат наружу, процесс завершён.
Послать что-либо работающему процессу нельзя, поэтому сработавший таймер агент
увидел бы только в следующий раз.

`codex app-server` держит сессию живой. Метод `turn/steer` добавляет сообщение
в текущий ход, `thread/queue/add` ставит его в очередь до освобождения треда.
Так будильник и реплика из Telegram доходят до агента, пока он занят.

Контекст растёт, но Codex сжимает историю автоматически (`contextCompaction`).
Пережить сжатие могут только файлы, поэтому агент ведёт заметки на диске и
перечитывает их при пробуждении.

## Транспорт до app-server

Supervisor запускает `codex app-server` дочерним процессом и говорит с ним
построчным JSON-RPC через stdin/stdout. Веб-сокет в документации помечен
экспериментальным, unix-сокет требует HTTP Upgrade — для одного локального
клиента stdio проще и надёжнее.

## Почему инструменты отдаются через MCP

Codex не кладёт секцию `tools` в запрос к модели: харнесс-инструменты доезжают
через code-mode host. Свои инструменты подключаются секцией `[mcp_servers.*]`
в конфигурации и появляются у агента рядом со встроенными.

Из этого следуют две особенности:

- без бинарника `codex-code-mode-host` не работает ни один инструмент;
- глобальный `approval_policy = "never"` инструменты MCP не разрешает, а
  блокирует; нужен `default_tools_approval_mode = "approve"` в секции сервера.

## Почему поиск — тоже MCP-инструмент

Штатный веб-поиск Codex обращается к `/v1/alpha/search`. Этого маршрута нет у
используемого шлюза, запрос возвращает 404, и агент сообщает об отсутствии
интернета. Инструмент `web_search` выполняет тот же поиск обычным вызовом
`/v1/responses` с `tools: [{"type": "web_search"}]` — движок тот же самый.

## Разделение журналов

`gateway` пишет в SQLite всё, что прошло через инструменты: вызовы, заявки,
срезы портфеля. Эту запись агент не выполняет и пропустить не может.

Заметки агента — отдельный слой: markdown-файлы в рабочей директории, его
собственная интерпретация происходящего. Расхождение между журналом и заметками
само по себе информативно.
